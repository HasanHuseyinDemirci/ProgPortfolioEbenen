# ProgPortfolioEbenen

CLI-Tool zur Bestimmung der Schnittmenge zweier Ebenen im R³ (parallel / identisch / Schnittgerade).

## Wie man es startet
Voraussetzungen: Python 3.8+

- Programm interaktiv starten:
```bash
python3 main.py
```
Eingabe per Terminal (T) oder aus CSV (Standard: `ebenen.csv`). Ergebnis wird in der Konsole angezeigt und kann optional in `output.txt` gespeichert werden.

- Tests ausführen (einfaches Testskript):
```bash
python3 test_programm.py
```
